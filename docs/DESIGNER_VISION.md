# Designer's Vision - Travel Schedule Book Experience

**Date**: January 31, 2026  
**Core Concept**: Digital version of decorating a physical travel schedule book

## 🎨 Design Philosophy

### The Nostalgic Experience
**"好似以前細個痴schedule book 咁"** (Like decorating schedule books when we were kids)

This app recreates the **joy and ritual** of planning trips with a physical schedule book:
- Placing cute stickers on pages
- Writing down all the details
- Organizing tickets and documents
- Making it personal and beautiful
- The satisfaction of a well-organized trip

### Core Feelings to Evoke

1. **Nostalgia** (懷舊)
   - Childhood memories of decorating notebooks
   - The tactile joy of placing stickers
   - Personal expression through decoration

2. **Ritual** (儀式感)
   - Creating a new project feels special
   - Each trip is a unique "book"
   - The process itself is enjoyable
   - Sense of accomplishment

3. **Organization** (整理)
   - Everything in one place
   - Easy to find information
   - Visual and intuitive
   - Satisfying to complete

4. **Personalization** (個人化)
   - Choose your own colors
   - Select your favorite stickers
   - Make it uniquely yours
   - Express your personality

const openInGoogleMaps = (location: string, coordinates?: {lat: number, lng: number}) => {
  const url = coordinates 
    ? `https://www.google.com/maps/dir/?api=1&destination=${coordinates.lat},${coordinates.lng}`

};

const applyTheme = (theme: ThemeCustomization) => {
  document.documentElement.style.setProperty('--color-primary', theme.primaryColor);

  }
};

### 6. Snow Animation (落埋雪)
**"仲可以落埋雪"**

**Animation Options**:

**Implementation**:
```typescript
// Snow particle system
const SnowAnimation: React.FC = () => {
  const [particles, setParticles] = useState<Particle[]>([]);
  
  useEffect(() => {
    // Generate snow particles
    const snowflakes = Array.from({ length: 50 }, (_, i) => ({
      id: i,
      x: Math.random() * window.innerWidth,
      y: -10,
      size: Math.random() * 3 + 2,
      speed: Math.random() * 2 + 1,
      drift: Math.random() * 2 - 1,
    }));
    
    setParticles(snowflakes);
    
    // Animate
    const animate = () => {
      setParticles(prev => prev.map(p => ({
        ...p,
        y: p.y > window.innerHeight ? -10 : p.y + p.speed,
        x: p.x + p.drift,
      })));
      
      requestAnimationFrame(animate);
    };
    
    animate();
  }, []);
  
  return (
    <div className="fixed inset-0 pointer-events-none z-50">
      {particles.map(p => (
        <div
          key={p.id}
          className="absolute rounded-full bg-white opacity-80"
          style={{
            left: p.x,
            top: p.y,
            width: p.size,
            height: p.size,
          }}
        />
      ))}
    </div>
  );
};
```

const createNewTrip = async (data: NewTripData) => {
  // 1. Create trip
  const trip = await tripService.create({
    name: data.name,
    destination: data.destination,
    startDate: data.startDate,
    endDate: data.endDate,
    travelers: data.travelers,
  });
  
  // 2. Apply theme
  await tripService.updateTheme(trip.id, {
    primaryColor: data.color,
    stickerStyle: data.stickerStyle,
    animation: data.animation,
  });
  
  // 3. Generate AI suggestions (if enabled)
  if (data.useAI) {
    const suggestions = await aiService.generateItinerary({
      destination: data.destination,
      duration: getDaysBetween(data.startDate, data.endDate),
      interests: data.interests,
    });
    
    await tripService.addSuggestions(trip.id, suggestions);
  }
  
  // 4. Generate themed stickers
  const stickers = await aiService.generateStickers({
    destination: data.destination,
    season: getSeason(data.startDate),
    style: data.stickerStyle,
  });
  
  await tripService.addStickers(trip.id, stickers);
  
  return trip;
};
```

## 📱 Core User Flows

### Flow 1: Planning a New Trip
```
1. Open app → See "Create New Trip" with cute animation
2. Choose destination → AI suggests stickers and theme
3. Set dates → Calendar with weather preview
4. Add flights → Upload PDF or manual entry
5. Add hotels → Upload confirmation
6. Plan activities → Drag and drop on timeline
7. Decorate → Add stickers to each day
8. Customize → Change colors, add snow effect
9. Share → Invite travel companions
```

### Flow 2: During the Trip
```
1. Open app → See today's schedule at a glance
2. Tap location → Opens Google Maps for directions
3. Check weather → See hourly forecast
4. View documents → Quick access to tickets
5. Add photos → Attach to activities
6. Update status → Check off completed activities
7. Add notes → Remember special moments
```

### Flow 3: After the Trip
```
1. Review trip → See all photos and memories
2. Add final notes → Write reflections
3. Share story → Create trip summary
4. Save as memory → Archive with all documents
